# Status

- Lifecycle: planned | active | blocked | paused | completed | archived
- Last updated: YYYY-MM-DD

## Current checkpoint

- Current task: State the active task in one sentence.
- Working state: State whether work is read-only, uncommitted, committed, pushed, blocked, or complete.
- Active plan: List only the remaining high-level steps needed to resume without old chat.
- Latest verified evidence: Record the most recent relevant check; distinguish local, remote, user-reported, and unverified evidence.

Replace this checkpoint after meaningful changes. Do not append a command log or duplicate details owned by decisions, bugs, roadmap, or references.

## Last verified progress

Describe the most recent work that has been completed and verified.

## Current blockers

List blockers that prevent progress. If none, write `None`.

## Next concrete action

State the single next action that should be taken when work resumes.

## Verification notes

Record evidence that supports the current status, such as tests, build results, review outcomes, or manual checks.
