## Continuation rule

When resuming a project, read in this order:
1. `README.md`
2. `STATUS.md`
3. `DECISIONS.md`
4. `BUGS.md`
5. `ROADMAP.md`
6. `REFERENCES.md` as needed

Create a new project by copying `projects/_template/` and then add it to this index.
