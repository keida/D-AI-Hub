# Memory

Store explicitly promoted, public-safe cross-project context that is useful across multiple projects but is not general subject knowledge. Keep private memory in OS-local SQLite or other private local state; this repository is not a private memory store.

Examples:
- stable workflow preferences
- environment conventions
- recurring operating rules
- long-term non-sensitive objectives

Do not store passwords, API keys, tokens, cookies, credentials, or unauthorized confidential material.

Daily capture and curation remain local by default. Promotion to this repository requires review for public safety; it does not imply commit, push, or GitHub publication.
